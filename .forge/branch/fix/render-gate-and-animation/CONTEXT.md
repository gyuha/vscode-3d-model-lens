## Language

**배경 모드 (Background Mode)**:
뷰어 캔버스 뒤에 보이는 색을 결정하는 세 값 중 하나 — `theme` · `light` · `dark`.
`theme` 은 VS Code 편집기 배경색을 따라가고, 나머지 둘은 그것과 무관하게 고정한다.
**모델의 색이 아니라 모델이 놓인 바탕의 색**이며, 사람 단위로 정해지는 것이지
파일마다 다를 이유가 없는 값이다(그래서 전역 설정에 저장한다).
_Avoid_: 배경색, 테마, 다크 모드

**측정 모드 (Measure Mode)**:
캔버스 클릭이 측정 점을 놓는 상태. **측정(개체)과 다르다** — 측정 모드는 켜고 끄는 상태이고,
측정은 그 상태에서 만들어지는 결과물이다. 뷰어 세션에 속하며 전역 설정에 저장되지 않는다
(배경 모드·그리드와 반대). 켜는 순간 애니메이션이 멈춘다 — 움직이는 메시에서는 측정이 의미를
잃기 때문이다. **진입점은 뷰어 패널 체크박스와 에디터 제목 표시줄 아이콘 둘이며, 둘은 하나의
공통 경로로 수렴한다** (Inspector 와 같은 구조).
_Avoid_: 측정 기능, 측정 툴, 재기 모드
